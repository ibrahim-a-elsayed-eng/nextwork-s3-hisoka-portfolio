Linux Log Watchdog & Hardening Practice

A training project on a demo app log (/var/log/demo-app/application.log) on Ubuntu WSL, combining general SSH hardening and UFW firewall rules with a Bash log-monitoring script running inside a hardened systemd oneshot service.

Environment
Ubuntu WSL (Training Project)
Script & Tools
Bash (log-monitor.sh), tail, grep
Process Supervisor
systemd (Oneshot, user log-monitor)
Hardening Practice
SSH, UFW, ProtectSystem=strict

1. Training Project Overview

This is a training project built on Ubuntu WSL using a demo application log (/var/log/demo-app/application.log):

  • Practiced general SSH hardening and UFW firewall rules on Ubuntu WSL.
  • Wrote a Bash script (log-monitor.sh) that reads the last 200 lines of /var/log/demo-app/application.log, counts lines with level=WARN and level=ERROR, writes a summary line to /var/log/log-monitor/report.log, and prints an ALERT message if there is at least one ERROR.
  • Ran the script as a systemd oneshot service (log-monitor.service) under a dedicated user log-monitor with sandboxing options.

3. Bash Script (log-monitor.sh)

Reads the last 200 lines of the demo app log, counts level=WARN and level=ERROR, appends a summary to /var/log/log-monitor/report.log, and prints ALERT to stderr if error_count > 0:

07-harden-log-monitor/scripts/log-monitor.sh 
#!/usr/bin/env bash
set -euo pipefail

source_log="${SOURCE_LOG:-/var/log/demo-app/application.log}"
report_log="${REPORT_LOG:-/var/log/log-monitor/report.log}"
window_lines="${WINDOW_LINES:-200}"

if [[ ! -r "$source_log" ]]; then
  printf 'ERROR source log is not readable: %s\n' "$source_log" >&2
  exit 1
fi

recent_log="$(tail -n "$window_lines" "$source_log")"
warning_count="$(grep -c 'level=WARN' <<<"$recent_log" || true)"
error_count="$(grep -c 'level=ERROR' <<<"$recent_log" || true)"
timestamp="$(date --iso-8601=seconds)"
summary="$timestamp source=$source_log window_lines=$window_lines warnings=$warning_count errors=$error_count"

printf '%s\n' "$summary" | tee -a "$report_log"

if (( error_count > 0 )); then
  printf 'ALERT errors=%s source=%s\n' "$error_count" "$source_log" >&2
fi

4. Systemd Oneshot Service (log-monitor.service)

Runs under the dedicated user log-monitor with NoNewPrivileges, PrivateTmp, PrivateDevices, ProtectSystem=strict, ProtectHome, ProtectKernelTunables, ProtectKernelModules, ProtectControlGroups, and UMask=0027:

07-harden-log-monitor/config/log-monitor.service 
[Unit]
Description=Scan the demo application log for warnings and errors
Documentation=man:systemd.service(5)
After=local-fs.target
ConditionPathExists=/var/log/demo-app/application.log

[Service]
Type=oneshot
User=log-monitor
Group=log-monitor
ExecStart=/usr/local/lib/log-monitor/log-monitor.sh
LogsDirectory=log-monitor
LogsDirectoryMode=0750
UMask=0027
NoNewPrivileges=yes
PrivateTmp=yes
PrivateDevices=yes
ProtectSystem=strict
ProtectHome=yes
ProtectKernelTunables=yes
ProtectKernelModules=yes
ProtectControlGroups=yes
