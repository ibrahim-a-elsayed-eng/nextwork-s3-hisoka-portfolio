Linux Disk Space Monitor & Health Daemon

Proactive storage health utility that audits mounted filesystems, computes usage percentages via awk and tr, triggers alerts at configurable thresholds, and executes through scheduled systemd timers.

Script Engine
Bash, df, awk, tr
Scheduler
Systemd Timer / Cron Daemon
Threshold Logic
Dynamic Check (> 80% Warning)
Source Repository
GitHub / linux-basics-project

1. The Infrastructure Risk: Root Partition Saturation

A full filesystem (especially / or /var) is one of the most common causes of silent production outages:

  • Databases crash immediately when write operations or temporary tables fail.
  • Systemd and Linux services fail to write pidfiles, causing cascading service crashes.
  • SSH authentication locks out administrators if /var/log/auth.log or temporary sessions cannot be written.

The Solution: A lightweight, automated monitoring script that checks partition utilization and records warnings before reaching critical capacity.

3. Production Bash Script (disk-monitor.sh)

The shell script extracted directly from the administration toolkit:

practice/disk-monitor-training/disk-monitor.sh 
#!/bin/bash
usage=$(df -h / | tail -n 1 | awk '{ print $5 }' | tr -d '%')
if [ $usage -gt 80 ]; then
  echo "$(date) $usage warning" >> /var/log/disk-monitor/disk-monitor.log
fi

4. Automated Scheduling via Systemd Timer

Configured as a periodic systemd timer for modern Linux distributions:

practice/disk-monitor-training/disk-monitor.timer 
[Unit]
Description=Run disk space monitor every 10 minutes
Documentation=man:systemd.timer(5)

[Timer]
OnBootSec=2min
OnUnitActiveSec=10min
Persistent=true

[Install]
WantedBy=timers.target
