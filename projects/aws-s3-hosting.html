1. The Engineering Problem: Costly Servers vs Static Needs

Hosting personal portfolios or documentation websites on standard virtual machines (e.g. AWS EC2, DigitalOcean Droplets) introduces unnecessary overhead:

  • Continuous Running Cost: Paying \$5 to \$20 every month for an idle server with underutilized CPU and RAM.
  • Security Maintenance: Regularly patching OS vulnerabilities, configuring firewalls, and managing SSH keys.
  • Single Point of Failure: If the VM crashes or its volume fills up, the portfolio goes offline.

The Solution: Leverage Amazon Simple Storage Service (Amazon S3) as a serverless static web server.

2. The Hosting Architecture & Request Flow

When a client visits the website endpoint, Amazon S3 evaluates bucket policies, confirms public read permissions for objects, serves index.html as the entry document, and routes any invalid keys to the customized error.html.

3. Least-Privilege Public Read Bucket Policy

To ensure objects are publicly readable by internet browsers while forbidding unauthorized uploads, deletions, or bucket modifications:

s3-public-read-bucket-policy.json 
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::hisoka-portfolio/*"
    }
  ]
}

4. Automated Deployment Workflow via AWS CLI

The entire portfolio deployment is managed with idempotent AWS CLI commands, enabling quick updates without manual AWS Management Console clicks:

AWS CLI Commands
# 1. Enable Static Website Hosting on S3 Bucket
aws s3 website s3://hisoka-portfolio/ \
  --index-document index.html \
  --error-document error.html

# 2. Disable S3 Block Public Access for website hosting
aws s3api put-public-access-block \
  --bucket hisoka-portfolio \
  --public-access-block-configuration "BlockPublicPolicy=false,RestrictPublicBuckets=false"

# 3. Synchronize local files to the bucket with content type headers
aws s3 sync . s3://hisoka-portfolio/ \
  --exclude ".git/*" \
  --exclude "*.md" \
  --delete
