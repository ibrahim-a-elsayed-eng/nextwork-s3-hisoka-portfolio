Hosting a Static Website on Amazon S3

I hosted a static website on Amazon S3 using the AWS console.

1. What I Built

  • An S3 bucket named nextwork-website-hisoka-portfolio in eu-north-1.
  • Uploaded 3 website files (211.3 KB): index.html, error.html, hisoka-banner.jpg.
  • Enabled static website hosting with index.html as the index document.

2. Steps

  1. Created the S3 bucket and set the public access settings.
  2. Uploaded the 3 website files (index.html, error.html, hisoka-banner.jpg).
  3. Enabled static website hosting and set index.html.
  4. Opened the website endpoint and got a 403 Forbidden error.
  5. Fixed it with: select objects > Actions > Make public using ACL.
  6. Later, I got an access denied error when deleting objects, and I fixed it by deleting the restrictive bucket policy.
  7. Finished the NextWork quiz with 5 out of 5.

3. Challenge (Problem / Diagnosis / Solution)

Problem
403 Forbidden on the website endpoint.
Diagnosis
The uploaded objects were private by default.
Solution
I made the objects public using ACL (select objects > Actions > Make public using ACL).
