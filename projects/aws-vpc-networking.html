1. The Networking Challenge: Isolation & Controlled Connectivity

Relying on the default AWS VPC exposes resources to flat network topologies where public and private workloads are not cleanly separated. To build production-grade cloud infrastructure, we needed:

  • Custom IPv4 address space planning (10.0.0.0/16) with dedicated subnetting for public-facing vs. internal resources.
  • Controlled internet ingress/egress via an attached Internet Gateway (IGW) and custom Route Tables.
  • Layered network defense combining stateful Security Groups (inbound HTTP/SSH rules) and stateless Network ACLs.
  • Reproducible infrastructure provisioning automated through the AWS CLI alongside Management Console verification.

3. Automated VPC Provisioning via AWS CLI

The core VPC, subnets, Internet Gateway, and public route table were provisioned and wired together using AWS CLI automation:

create-custom-vpc.sh (AWS CLI) 
# 1. Create Custom VPC (10.0.0.0/16)
VPC_ID=$(aws ec2 create-vpc --cidr-block 10.0.0.0/16 \
  --tag-specifications 'ResourceType=vpc,Tags=[{Key=Name,Value=Hisoka-Custom-VPC}]' \
  --query 'Vpc.VpcId' --output text)

# 2. Create Public Subnet (10.0.1.0/24) & Private Subnet (10.0.3.0/24)
PUB_SUBNET=$(aws ec2 create-subnet --vpc-id "$VPC_ID" --cidr-block 10.0.1.0/24 \
  --tag-specifications 'ResourceType=subnet,Tags=[{Key=Name,Value=Public-Subnet-1}]' \
  --query 'Subnet.SubnetId' --output text)

PRIV_SUBNET=$(aws ec2 create-subnet --vpc-id "$VPC_ID" --cidr-block 10.0.3.0/24 \
  --tag-specifications 'ResourceType=subnet,Tags=[{Key=Name,Value=Private-Subnet-1}]' \
  --query 'Subnet.SubnetId' --output text)

# 3. Create & Attach Internet Gateway (IGW)
IGW_ID=$(aws ec2 create-internet-gateway \
  --query 'InternetGateway.InternetGatewayId' --output text)
aws ec2 attach-internet-gateway --vpc-id "$VPC_ID" --internet-gateway-id "$IGW_ID"

# 4. Configure Public Route Table & Associate Public Subnet
RTB_ID=$(aws ec2 create-route-table --vpc-id "$VPC_ID" \
  --query 'RouteTable.RouteTableId' --output text)
aws ec2 create-route --route-table-id "$RTB_ID" --destination-cidr-block 0.0.0.0/0 --gateway-id "$IGW_ID"
aws ec2 associate-route-table --subnet-id "$PUB_SUBNET" --route-table-id "$RTB_ID"
